# DECISIONS.md

## ADR-001 — Framework

### Decisión

Utilizar Flutter y Dart.

### Motivo

Permite desarrollar una aplicación multiplataforma
manteniendo una única base de código.

---

## ADR-002 — Arquitectura

### Decisión

Utilizar separación Presentation / Domain / Data / Core.

### Motivo

Facilitar mantenimiento, testing y evolución del proyecto.

---

## ADR-003 — Fuentes

### Decisión

Trabajar únicamente con información disponible públicamente
y mediante mecanismos autorizados.

### Motivo

Mantener el proyecto dentro de límites legales y éticos.

---

## ADR-004 — Dependencias

### Decisión

Mantener el número de dependencias externas al mínimo.

### Motivo

Reducir complejidad, vulnerabilidades y mantenimiento.
